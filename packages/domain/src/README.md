# Domain Source

**Path:** packages/domain/src/

## Purpose

Organizes the pure domain model by robot, mission, map, traffic, and shared primitives.

## Responsibilities

Keep invariants close to the entities and value objects that enforce them.

## Boundaries

Cross-domain behavior should be modeled explicitly rather than hidden in generic helpers.

## Completion expectations

Document public interfaces, validate external inputs, add focused tests, and define logs/metrics before considering this area production-ready.
