# Robot Adapter SDK Source

**Path:** packages/robot-adapter-sdk/src/

## Purpose

Organizes the public adapter API, capabilities, conformance rules, and testing support.

## Responsibilities

Keep the SDK small, stable, documented, and usable without Fleet Server internals.

## Boundaries

Breaking changes require an explicit SDK version and migration guide.

## Completion expectations

Document public interfaces, validate external inputs, add focused tests, and define logs/metrics before considering this area production-ready.
