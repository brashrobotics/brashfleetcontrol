# OpenAPI Contracts

**Path:** packages/contracts/openapi/

## Purpose

Defines the public REST API contract.

## Responsibilities

Describe endpoints, authentication, request/response schemas, status codes, pagination, idempotency, and standard errors.

## Boundaries

Changes require compatibility review and generated-client updates.

## Completion expectations

Document public interfaces, validate external inputs, add focused tests, and define logs/metrics before considering this area production-ready.
