# Shared Test Kit

**Path:** packages/test-kit/

## Purpose

Provides reusable test data builders and infrastructure substitutes.

## Responsibilities

Offer robot/mission/map builders, fake adapters, fake clocks, in-memory repositories, polling helpers, and domain-specific assertions.

## Boundaries

Keep test helpers deterministic and independent of production credentials or customer data.

## Completion expectations

Document public interfaces, validate external inputs, add focused tests, and define logs/metrics before considering this area production-ready.
