# Applications

**Path:** apps/

## Purpose

Contains processes that can be started or deployed directly. Applications assemble reusable packages and expose product capabilities.

## Responsibilities

Own executable entry points, runtime composition, process lifecycle, and deployment-facing configuration.

## Boundaries

Do not place reusable domain rules or vendor-specific protocol models here.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
