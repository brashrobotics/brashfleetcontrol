# Operator Console

**Path:** apps/operator-console/

## Purpose

The browser application used to monitor and operate the Fleet platform.

## Responsibilities

Present fleet state, maps, missions, traffic, alarms, and authorized controls through published APIs.

## Boundaries

Never connect directly to the database, brokers, or robot adapters.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
