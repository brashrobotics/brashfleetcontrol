# Operator Console Assets

**Path:** apps/operator-console/src/assets/

## Purpose

Stores static visuals bundled with the web application.

## Responsibilities

Keep icons, fonts, generic images, and UI-only resources here with clear licensing metadata.

## Boundaries

Factory maps and customer operational data must be loaded from Fleet APIs, not embedded as assets.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
