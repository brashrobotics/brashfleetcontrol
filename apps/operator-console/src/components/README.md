# Shared UI Components

**Path:** apps/operator-console/src/components/

## Purpose

Contains reusable, presentation-focused UI building blocks.

## Responsibilities

Provide accessible buttons, forms, tables, dialogs, badges, layout primitives, and loading/error states.

## Boundaries

Components must not contain robot-vendor behavior or mission-assignment policy.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
