# Operator Console Features

**Path:** apps/operator-console/src/features/

## Purpose

Groups UI implementation by operator-facing capability.

## Responsibilities

Create feature folders such as fleet-map, robots, missions, traffic, alarms, and settings with their views, state, and API hooks.

## Boundaries

Avoid importing internal files across features; expose narrow feature entry points.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
