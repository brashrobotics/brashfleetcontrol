# Simulator Scenarios

**Path:** apps/robot-simulator/src/scenarios/

## Purpose

Defines repeatable multi-robot operating situations.

## Responsibilities

Model normal shifts, queue pressure, capability mixes, traffic conflicts, charging queues, and site-specific workloads.

## Boundaries

Scenarios declare behavior and data; reusable simulation mechanics stay in engine.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
