# Robot Simulator Source

**Path:** apps/robot-simulator/src/

## Purpose

Contains the simulator runtime, scenario definitions, fault injection, and reusable fixtures.

## Responsibilities

Keep the simulation deterministic, scriptable, and compatible with the Robot Adapter contract.

## Boundaries

Do not import Fleet Server internals to fake successful behavior.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
