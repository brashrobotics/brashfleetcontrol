# Charging Module

**Path:** apps/fleet-server/src/modules/charging/

## Purpose

Plans charging activity and protects mission execution from insufficient energy.

## Responsibilities

Define battery thresholds, charger compatibility, charging queues, station reservations, opportunity-charging policy, and energy estimates.

## Boundaries

The robot remains responsible for local battery protection and charger control.

## Completion expectations

Public interfaces must be documented, inputs validated, relevant tests added, and operational logs/metrics defined before this area is considered production-ready.
