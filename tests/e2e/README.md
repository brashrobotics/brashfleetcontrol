# End-to-End Tests

**Path:** tests/e2e/

## Purpose

Verifies complete operator and mission workflows across running applications.

## Responsibilities

Cover mission creation, eligibility, assignment, dispatch, acknowledgment, execution, completion, pause/resume/cancel, and UI-facing APIs.

## Boundaries

Keep the core suite small and reliable; detailed edge cases belong at lower test levels.

## Completion expectations

Keep this README current as implementation is added, and define ownership, validation, tests, and operational behavior for production use.
