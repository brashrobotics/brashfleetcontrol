# Environment Configuration

**Path:** config/

## Purpose

Contains non-secret configuration organized by runtime environment.

## Responsibilities

Provide documented development, test, and production defaults that are validated by packages/config.

## Boundaries

Secrets and customer-specific sensitive values must come from deployment-time secret management.

## Completion expectations

Keep this README current as implementation is added, and define ownership, validation, tests, and operational behavior for production use.
