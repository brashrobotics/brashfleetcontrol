# Production Configuration

**Path:** config/production/

## Purpose

Documents non-secret production defaults and required deployment inputs.

## Responsibilities

Define log levels, connection limits, feature flags, retention settings, security requirements, and mandatory variables.

## Boundaries

Do not commit production credentials, private keys, certificates, or customer network details.

## Completion expectations

Keep this README current as implementation is added, and define ownership, validation, tests, and operational behavior for production use.
