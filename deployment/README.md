# Deployment

**Path:** deployment/

## Purpose

Contains reproducible artifacts for running Fleet Control in supported environments.

## Responsibilities

Document image creation, local/pilot composition, production orchestration, monitoring, upgrade, and rollback.

## Boundaries

Deployment files consume built artifacts and configuration; they must not contain product business logic or secrets.

## Completion expectations

Keep this README current as implementation is added, and define ownership, validation, tests, and operational behavior for production use.
