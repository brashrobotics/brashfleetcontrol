# Project Scripts

**Path:** scripts/

## Purpose

Contains repeatable developer and operations commands that support the repository.

## Responsibilities

Provide environment validation, build/schema generation, migrations, demo-data loading, map validation, and conformance-test entry points.

## Boundaries

Scripts must call product interfaces or shared libraries rather than reimplementing business rules.

## Completion expectations

Keep this README current as implementation is added, and define ownership, validation, tests, and operational behavior for production use.
