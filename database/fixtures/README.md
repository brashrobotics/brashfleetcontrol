# Database Test Fixtures

**Path:** database/fixtures/

## Purpose

Contains fixed datasets used by integration and end-to-end tests.

## Responsibilities

Provide minimal, deterministic database states that can be recreated for each test suite.

## Boundaries

Fixtures serve tests only; development demo data belongs in seeds.
